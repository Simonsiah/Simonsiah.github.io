Privacy Policy · Pinnacle Drive Tools

Last updated: 21 October 2026

Pinnacle Drive Tools is an internal tool run by Pinnacle Thinkers (Mindcraft Debate Sdn. Bhd.), 62, Jalan PJU 5/21, Kota Damansara, 47810 Petaling Jaya, Selangor, Malaysia.

What data the tool accesses

With the account owner's permission, the tool reads and writes files in Pinnacle Thinkers' own Google Drive and Google Sheets. It is used only with our own Google account.

How the data is used

The data is used only to organise our files and to create and update score sheets for tournaments we organise. It is processed on our own computers.

Sharing

We do not sell, rent or share Google user data with third parties, and we do not use it for advertising.

Storage and deletion

Access tokens are stored only on our own computers. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Our use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
